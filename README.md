# Befroosh

> All-in-one Instagram sales and smart DM automation platform.

Befroosh is an approved Meta Business Partner platform designed to automate Instagram comment replies and direct messages, capture customer leads, showcase products, and scale sales inside DMs without requiring a third-party website.

## Features

- **Smart DM Automation**: Instant, keyword-triggered automated responses to comments and story mentions.
- **In-Chat Storefront**: Showcase products and process customer orders directly inside Instagram DMs.
- **Lead Generation**: Automatically collect contact numbers and customer details inside conversations.
- **Official Meta Integration**: Built using official Instagram Graph APIs — zero risk, no account passwords needed.
- **High-Performance Architecture**: Built with Next.js 16 (Turbopack), Tailwind CSS, and TypeScript.

## Getting Started

### Prerequisites

- [Bun](https://bun.sh/) (recommended) or [Node.js](https://nodejs.org/) (v18+)

### Installation

```bash
bun install
# or
npm install
```

### Development Server

```bash
bun dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Icons & Graphics**: Custom SVG & official Meta/Instagram brand assets
